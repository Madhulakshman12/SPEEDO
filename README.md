# APEX AUTO // Luxury & Performance Car Rental System

A supercar and performance vehicle rental management system built with React, Vite, Tailwind CSS, and Zustand, modeled on a Supabase/PostgreSQL schema.

## 🏎️ Key Features
- **Exotic Fleet Catalog & Location Filtering**: Filter supercars, luxury SUVs, and high-performance EVs across key metropolitan hubs (LAX, Miami, SF).
- **Comprehensive Vehicle Specs**: Horsepower, 0-60 mph acceleration benchmarks, top speed, and transmission specs.
- **Loyalty Tier Discount Engine**: Automatic rate calculation with Apex Black 15% VIP discounts.
- **Digital Lease Agreement**: Integrated electronic terms signature and liability waiver.
- **Pre-Pickup Vehicle Telemetry & Damage Verification**: Pre-existing damage photo logging for liability tracking.
- **Fleet Maintenance Console**: Track brake inspections, tire rotations, and schedule automated servicing.
- **AI Vehicle Photo Synthesizer**: Auto-generate realistic supercar listing photography for new fleet entries.

## 🚀 Quickstart
Start the backend and frontend in separate terminals. The backend requires the MySQL service and the credentials configured in `backend/db.js`.

Backend:
```bash
cd backend
npm start
```

Frontend:
```bash
npm install
npm run dev
```
